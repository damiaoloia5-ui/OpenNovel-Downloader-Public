# 起点自动逐章保存实验验证

日期：2026-10-25。修改前为干净 `main`，基线 `a57995a`。schema 8 不变。本记录区分已实现、受控验证、构建交付和真实官网验收。

## 已实现范围

- 从已确认的起点完整目录创建全书或序号范围任务，复用 jobs/job_items 与事务保存；已有正文跳过。
- 账户内串行正常章节导航，最小间隔 3 秒、单章截止 30 秒、两次相同 DOM 结果确认。校验作品、章节、标题和字数；页面保护、试读、订阅、可见验证框及未知结构停止。
- 暂停、取消、显式选择账户继续；重开软件复用原任务进度，需重新打开官网会话。失败或受限停止后不继续访问后章，不无限重试。
- 账户页进度/错误、书库“自动保存本书正文”、任务页“选择账户继续”、已有书库 TXT/EPUB 导出。
- 启动和继续前要求本人确认官网关闭自动订阅；不点击订阅，不读取凭据，不扩大远程页面 IPC 权限，不开放普通 HTTP 或批次入口。

设计见 [ADR 0010](../adr/0010-account-bound-automatic-saving.md)，操作见 [使用指南](../USER_GUIDE.md)。

## 原生交互未完成项

已从之前自有验证书库建立独立副本（一个 984 章目录、已存公开首章），不复制浏览器会话。独立原生进程成功启动，但获取原生窗口控制时授权等待超时；没有继续操作或绕过该授权。验证进程已清理。

因此，本轮**没有**执行以下官网自动队列验收：连续保存第 1～3 章、执行中暂停与继续、关闭重开后的原生续传、匿名 VIP 订阅页面实际停止。上述机制的核心回归通过不能替代原生 WebView 回调和真实官网测试。前一轮手动保存公开首章的记录仍独立保留，不能挪作自动保存证据。

真实本人登录、已购/未购差异、登录失效、已订阅全书覆盖仍待本人配合。自动任务如无法识别完整正文会保留缺章，不声明通用 VIP 可用。书旗和其他来源能力不因本轮变化。
