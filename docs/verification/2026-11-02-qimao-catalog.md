# v0.3.11 七猫目录缓存兼容与渠道说明

日期：2026-11-02；基线 `8e70494`。用户反馈作品 `https://www.qimao.com/shuku/13030701/` 在导入时提示“七猫目录最新章节与作品页身份不符”。另纠正网页目录字段与 App 免费阅读的混淆。

## 根因与改动

- 同次读取的作品页声明 178 章，但“最新章节”小组件指向第 176 章（1791973744）；目录接口返回 178 章，最后一章 ID 1792011017。最新小组件滞后，旧实现强制链接等于目录末项而拒绝导入。
- 仍核对本书 routePath、完整数量、索引与排序连续性、ID 唯一性及已知限制标记；将最新小组件与本书完整目录中的对应 ID/标题核对，允许它滞后。异域、其他书、未知章节、标题不符及不完整目录仍拒绝。
- 原创三章 fixture 模拟最新链接停在第二章：修改前失败，修改后通过，并覆盖上述拒绝条件；真实作品正文不加入测试仓库。
- 七猫目录 `is_vip=1` 不再被文案直接解释为“需付费订阅”。适配器、来源说明及未保存原因明确网页渠道限制与官方 App 免费阅读的区别；未将该标记直接放行为可下载。
- schema 9 不变，既有作品信息导出、保存位置和简洁文件名保留。
