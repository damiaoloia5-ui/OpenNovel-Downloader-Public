# v0.3.9 番茄正文计数误判修复

日期：2026-11-02。修改前基线 f0ec6e9，工作区干净；未改数据库 schema、引擎二进制、网络出口或权限规则。

## 原因与修复

用户截图的来源是 `fanqie-app-local`，实际任务不是网页十章限制。只读查询原书库发现第 2 章被拒绝：正文非空白字符数 3031，返回 `word_number=3027`。第一章已保存，第二章失败，其余 114 章未执行。

独立隔离读取当前目录 116 章，全部明确 `need_pay=0`，其中 61 章非空白 Unicode 字符数与字数字段不同。第 2 章差额恰为 4 个 `·`；另外存在圆圈数字、箭头、罗马数字、假名及零宽字符等差异。按 ASCII 可见字符、基本汉字、中文标点区、全角区及常见引号/破折号/省略号计数，与本次 116 章字数字段全部一致。这是样本观察得到的校验口径，未获得平台公开规范，不推定覆盖所有作品。

核心保留原样正文，增加上述精确计数比较；只有具备完整 header/article/footer 结构时才接受第二口径。原有精确非空白字符数口径保留，移除原先每千字允许少量不明增字的容差。身份、标题、免费标记、大小、异常结构、试读提示等校验不变。少一个普通正文字符、添加未解释文字、缺失闭合结构仍失败；字数相符本身不能证明远端文本逐字正确。

工作台使用本地引擎专用恢复说明，并直接展示任务错误。校验失败不再提示去起点或官网窗口登录；限流、验证和权限错误仍停止，不自动解验证或提高访问权限。
