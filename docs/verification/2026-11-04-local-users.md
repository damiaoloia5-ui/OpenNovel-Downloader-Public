# 独立用户与干净分发验证

日期：2026-11-04。变更前工作区干净，基线提交 `3d54838`。本次不修改平台获取能力，不使用真实账号、正文或 Computer Use。

## 行为

- 软件内可新建空白用户、切换用户；用户 ID 随机生成，名称只作显示。不同系统用户另有独立应用数据根目录。
- 每个用户有独立数据库、任务、账号记录、导出历史、WebView 偏好、临时官网会话、引擎选择和默认导出目录。默认导出不再写到共享程序目录；手动选公共目录仍会共享文件。
- 原默认书库自动登记保留原路径；显式旧库可登记，不能重复把同一个实际数据库登记成两个用户。新用户不会复制旧书库。
- 保存／导出执行期间不能切换。切换采用新进程和独立 WebView 目录，新窗口初始化并返回一次性就绪标记后才退出原进程；新进程失败或超时保留当前窗口。原官网会话随旧进程关闭。
- 用户注册表加排他锁和原子替换；未知 ID、损坏配置不回退到别人的书库。同一书库保持排他写入锁。
- CLI 默认使用当前系统用户选中的书库，支持 `--profile`；显式 `--database` 仍可使用，默认导出按数据库分开。

软件内用户是数据组织边界，不是密码认证、加密或系统权限隔离。同一 Windows 账号下的人可以主动切换用户。需要互相保密时使用独立 Windows 账号。
