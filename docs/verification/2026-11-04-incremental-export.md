# 大书库刷新、选章导出与恢复提示

2026-11-04，基线 cdc3a60。本轮为未发布源码改进，版本字段仍为 0.3.20；已发布安装包、桌面快捷方式和 dist/installers 内交付文件没有替换。

## 实现与保护

- 选章导出在 SQL 层过滤章节 ID，再解析正文；保持目录顺序和缺章统计。任务历史快照导出仍沿用既有路径，不伪称全部导出已经流式化。
- 自动 Word/EPUB 生成的临时文件连同摘要一起交给持久化步骤，避免新文件二次渲染；保留摘要复核、原文件修改检测、不覆盖落盘和导出记录规则。
- 核心提供 snapshot_if_changed，版本由本次书库实例 ID、SQLite total_changes 和 data_version 组成。令牌与快照在同一连接锁内读取；重开书库令牌失效，不需要修改数据库 schema。回滚导致额外刷新可以接受，不得遗漏已提交修改。
- 界面无变化时不重新取整库、偏好及任务明细；自动导出状态保持独立更新，读取失败不提前推进版本。后台无变化时不再每秒聚合整库，保留五秒文件丢失检查与显式重试。仍是有界轮询，不声称已实现逐书事件推送。
- 章节明细恢复提示优先使用后端已有 error_kind，区分校验、限制、网络和文件问题；历史任务/任务级提示保留文本兼容。未增加自动解验证码或绕过平台冷却的行为。
- 添加链接时显示来源说明；提示只做精确主机匹配展示，不替代后端完整地址验证，也不表示获取了正文权限。

## 升级验收与剩余边界

本轮不改更新安装流程、数据目录或 schema。全量回归复验既有备份、文件保护、迁移和进程中断恢复；原生自检仅使用原创临时书库。

独立 Windows 上的真实跨版本交互更新仍待验收。后续验收应在一次性虚拟机中从旧发布包创建两位原创用户，各存书籍、设置和外部导出文件；升级后逐项比较内容摘要、选章/格式设置和用户列表，测试下载取消、磁盘不足、安装中断及重启，并核对恢复备份。不得在用户真实书库上注入故障或把同版本 `/UPDATE` 模式当作跨版本证明。

本轮没有真实平台请求、账号权益验收、原生窗口视觉检查或 Computer Use。没有更新依赖审计数据，不能把此轮测试说成新一轮完整安全审计。正式 Authenticode、七猫 App 通道、真实已购全书、目录插删重排合并及完全事件驱动刷新仍是单独后续工作。
