# 队列与正文校验算法验证

日期：2026-10-30；干净基线 c861fc7。按用户要求优化算法，本轮不进一步降低请求间隔，不使用 Computer Use 或其他窗口控制。

## 算法

- 建立任务时一次读出本书已存章节 ID 集合，代替逐章查缓存；复用 job_items 插入的预编译语句。
- 运行前以一次事务同步“队列仍未完成但正文已存在”的项，失败整体回滚。普通新任务原本就会识别缓存，因此不将这部分描述为首创跳过已存正文。
- 待保存元数据只读取一次，再按目录顺序执行，避免每章重复队列 SQL、选章 JSON 集合解析和缓存探测。保留每章运行状态/取消检查。合法目录最多 10000 项；不预取全文进内存，不并发官网窗口。
- 高频 SQL 复用预编译结果；正文 JSON 序列化移到数据库写事务之前，减少持锁时间。正文与完成标记仍逐章同事务提交，WAL/synchronous=FULL 不变。
- 统一结构化校验与 JSON 导入的 normalize 规则。对已解析章节直接校验，流式计数序列化字节以保留 16MiB 预算，移除整个 JSON 副本和再次解析。ID/标题、空文、无效 XML 字符、去空白及去空段规则不变。
