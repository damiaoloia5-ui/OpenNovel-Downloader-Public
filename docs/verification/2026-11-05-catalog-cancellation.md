# v0.3.24 目录读取取消

源码基线 `8793e60`。任务开始时工作区干净，后续改动均属于目录取消、回归测试和版本配置。

## 实现范围

添加小说的公共网页识别流程提供“停止读取”。离开当前页面也会申请停止，读取结束后可重新开始。独立请求标识贯穿初次识别、番茄本地增强目录复查和创建下载任务前的目录复查。

番茄、七猫、书旗、晋江、纵横、17K、刺猬猫、飞卢和咪咕的公共目录适配器将同一取消信号传给 HTTP 层，分页沿用该信号。旧调用者仍可使用原有 `inspect` 接口。网络调度等待、重试等待和正文传输通过现有 HTTP 取消机制释放请求。

桌面请求管理器对取消与最后的数据库事务加锁排序。取消先完成时拒绝建任务，事务先完成时界面展示已创建的任务。迟到的清理请求只作用于相同标识，重试会分配新标识。目录请求仍活跃时，切换用户会提示先停止读取。注册和取消 IPC 在阻塞工作线程处理，避免锁竞争阻塞窗口消息线程。

组件首次准备阶段会等待当前准备操作结束后响应停止，界面保持等待提示。账户窗口读取、批量队列和书库目录更新沿用各自已有控制流程。
