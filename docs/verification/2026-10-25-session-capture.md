## 已实现流程

- 固定脚本读取本账户官网窗口中正常显示的完整目录或当前正文，不请求其他章节，不读取凭据、输入值、Cookie、storage 或隐藏应用状态。
- 先读取并确认完整目录，再逐章预览并确认保存。预览绑定账户/会话、10 分钟有效，确认后消费；导航变化与超时拒绝，关闭窗口使预览失效。
- 核心校验来源、作品、章 ID、目录完整数量、声明字数及 XML 安全字符。未知结构、可见订阅提示、保护字形或过短正文拒绝。字数阈值是启发式，不能代替用户核对正文首尾。
- 单章正文和 completed 状态同一事务；重复相同内容不新建任务，内容变化不覆盖；目录顺序独立于章节 ID 与保存时间，更新仅接受末尾增章并保存历史。
- 复用现有离线阅读与 TXT/EPUB 导出。目录没有正文时返回明确提示，缺章导出保留缺失标记。批量下载能力保持关闭，账户状态不宣称已认证。
