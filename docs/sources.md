网络来源的准入记录必须包含真实样本、日期、实现版本、账户前提、目录覆盖、正文正确性、错误分类、限流行为和外部获取渠道。仅可读网页或项目声称可下载不能证明 OpenNovel 已接入。

本轮扩展研究见 [晋江与起点](research/jinjiang-qidian.md)。起点当前正常访问返回 202 验证页；书旗正文仍为 429。二者账户测试由用户在官方页面配合，不能推断为正文已可用。

开发分支正文适配器为 `fanqie-web`、`qimao-web`、`jinjiang-web`；书旗 `shuqi-web` 仅 inspect。核心 SourceHub 向 GUI/CLI 提供同一能力清单，书旗 can_download=false，核心在建任务前也拒绝。恢复任务按持久来源 ID 路由；作品身份仍为 (source, remote_id)。暂不引入动态代码插件。

书旗目录项 restricted=false 仅表示未见明确限制标记，**不构成可读承诺**；界面显示“正文访问未验证”。七猫只接受明确的 0/1 权限字段，缺失或未知值拒绝目录。纯数字输入保留番茄语义，其他平台使用官方详情链接或 qimao:ID、shuqi:ID，不猜测跨平台 ID。

番茄历史样本在 2026-10-20 实测，本轮另通过 CLI 首章回归。均为公开网页、无账户、无第三方正文接口；番茄字体通过官方资源与 Adobe 思源黑体的唯一字形匹配还原。测试不把在线正文提交仓库或用于普通 CI。样本、哈希与限制见 [番茄研究](research/fanqie-web.md)。首版范围经用户确认限定为官网实际开放正文，App 正文后续扩展；免费标签不保证网页可读。

七猫限定主章节容器，检查身份、标题和声明字数，排除其他作品的推荐段落。长度检测是保守启发式，不能证明全站逐字正确。各来源独立域名名单和请求间隔，保留大小/超时预算、取消、受控重定向与 Retry-After。七猫当前响应存在旧式 HTTP 折行头，仅其客户端启用对应兼容；不关闭证书校验，不全局忽略无效头。

2026-10-21 的研究、原生重启继续与安装包证据见 [七猫/书旗研究](research/qimao-shuqi-web.md)、[v0.2 验证](verification/2026-10-21-multi-source.md)、[实施方案](MULTI_SOURCE_PLAN.md) 和 [架构决策 0005](adr/0005-source-registry-and-capabilities.md)。下一步复验书旗正文、扩大七猫样本、补独立干净 Windows 门禁，再研究起点/晋江公开目录与免费试读。

v0.1 新增离散选章、在途 HTTP 中止、独立暂停、任务选章导出、离线预览和导出记录。2026-10-20 对真实五章样本选 1/3/5，补齐书库到 5/5 后仍只导出三章；原生端同样验证。完整验收及未完成的干净 Windows 检查见 [v0.1 记录](verification/2026-10-20-v01.md)。

第一版先完成免费平台可用闭环和发布验收。付费平台按目录/免费试读、账户、已购内容逐步研究；未购买 VIP 内容获取没有已实现或必达承诺。

本轮新增逐章状态/错误明细、指定失败章节重试、目录末尾增章及检查更新。当前目录未变化时也可创建补齐任务，复用已保存内容、重新确认受限项；删章、插章和重排仍拒绝更新。该能力没有扩大网页正文的访问权限。定向重试、增章与访问状态变化使用原创受控样例验证，真实官网目录更新检查另记在线结果，不能混同为已观察到远端实际增章。

本地入口已通过核心/CLI 测试及 Windows 原生界面的导入、取消、继续、重启读取和导出验证，具体范围见 [验证记录](verification/2026-10-20-foundation.md)。这项证据不适用于商业来源。

开发分支 schema 7 已增加目录变更预览、显式接受与修订历史；原有自动补齐入口继续拒绝删除/重排，需改用显式确认入口。历史保存/导出不扩大来源权限，见 [验证](verification/2026-10-21-revisions.md)。

账户实验已提供起点/书旗隔离临时官网窗口、退出清理与 IPC 边界，不保存凭据、不声明登录和已购正文可用。2026-10-21 起点用户样本 1045749425 在新窗口为空白验证页，书旗首页可显示。见 [账户验收边界](verification/2026-10-21-accounts.md)。
