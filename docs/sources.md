第一份真实适配器为 `fanqie-web`，当前契约提供目录与逐章正文；引擎管理请求后的保存、取消与恢复。第二来源尚未验证，暂不冻结通用插件框架。

实现版本：0.0.1 开发预览，当前变更集。公开网页、无账户、无第三方正文接口；字体通过官方网页资源与 Adobe 思源黑体的唯一字形匹配还原。测试不把在线采集正文提交仓库或用于普通 CI。样本、哈希、响应限制、错误分类和已知缺口见 [来源研究记录](research/fanqie-web.md)。

第一版先完成免费平台可用闭环和发布验收。付费平台按目录/免费试读、账户、已购内容逐步研究；未购买 VIP 内容获取没有已实现或必达承诺。

本地入口已通过核心/CLI 测试及 Windows 原生界面的导入、取消、继续、重启读取和导出验证，具体范围见 [验证记录](verification/2026-10-20-foundation.md)。这项证据不适用于商业来源。
