# OpenNovel 使用指南

对应 0.3.0 自动 TXT 候选版，2026-10-28。未验收的能力见 [来源状态](sources.md) 与 [阶段清单](REMAINING_PHASES.md)。

## 默认自动得到 TXT

2026-10-30 算法候选版继续减少长目录的重复查询与正文重复解析，不改变操作或请求节奏。软件会一次载入待保存元数据，正文仍逐章校验、同事务保存及检查取消；已有正文不重复请求。首次下载受网站等待影响较大，本地基准不代表官网总耗时。请从本轮“启动算法优化版”入口运行；旧桌面入口若未更新可能仍运行较早版本。

添加普通已支持网页链接后点击“识别并保存为 TXT”，会自动识别平台、读取目录、选择全部标记开放章，创建保存任务并打开本书工作台。“只看获取范围”和高级选章保留。书旗或零开放章只显示范围说明，不启动无效任务；起点仍转到本人登录/目录/确认流程，不自动确认权益或购买。

桌面后台每秒检查轻量书库/任务快照，不依赖前端轮询、页面可见性或最小化状态。有正文且本书没有 queued/running 任务时，自动生成 TXT，包括完成、部分、失败、暂停、取消后的已有内容及启动时的已有书库。空书不生成；只重启页面不会新增同版本文件，后台也不请求正文或改变任务。正文修订和显式目录更新另外通知后台。

工作台顶部“自动 TXT 文件”显示实际路径、保存章数、部分内容与错误，并可打开文件夹或重试。目录为该书库的 `exports/automatic-txt`；文件名含安全书名、作品身份及正文哈希。不同版本保留，未保存章不伪造。相同内容校验字节后复用记录；文件删除后在重启或显式重试恢复；目标内容被编辑则拒绝覆盖并要求先移走。文件落盘但记录写入失败时下次可校验并补记。

自动导出失败不改保存任务结果、不删书库正文；同一状态不每秒无限重试，需本人修复后明确重试或重启。状态提示在内存中，重启后从持久正文、任务与导出记录重建。CLI 原有下载/导出语义保持不变，自动后台是桌面功能，核心生成方法由两端共用。EPUB 和原手动导出继续可用，手动格式偏好不影响固定 TXT。

## 安装与首次使用

Windows x64 安装器按当前用户安装；不需要 Node、Rust 或 Java。运行需要 WebView2，缺失时安装器尝试下载引导程序。安装包未签名，其他系统与干净 Windows 尚未完整验收。

首次可先导入仓库的 `examples/local-book.json`，验证导入、离线阅读和导出。正式书库保存在系统应用数据目录 `org.opennovel.downloader`；CLI 默认使用当前目录的 `.artifacts/library.db`。不要让 CLI 和桌面同时打开同一书库。

## 获取公开内容

在“添加小说”粘贴官网作品链接，读取目录后确认平台、书名、章节总数和限制。番茄、七猫、晋江可下载经过验证的公开正文；书旗当前只读详情和目录。纯数字沿用番茄 ID；其他来源用 `qimao:ID`、`shuqi:ID` 或 `jinjiang:ID`。

选择连续范围或填写 `1,3,5-8`。界面展示的是本次所选集合；“所选完成”不等于整书保存完整。网页不可读、VIP 或锁定项保留受限状态，不用预览片段填充正文。晋江可通过界面搜索，返回当前官网首屏最多 20 项，不是全站全文搜索。

“任务进度”中任务每页最多显示 20 项，可筛选进行中与暂停、失败/部分/受限、已完成任务。可暂停、取消、继续、查看逐章原因和只重试失败章。429 或临时网络失败会停止本轮请求，按提示等待后手动继续。受限章节不能直接强行重试，应先重新检查官网目录。

批次输入每行一个作品，最多 10 个输入；自动按来源和作品 ID 去重。默认每本前 3 章，也可指定集合。每次只执行一本；暂停后继续复用原任务，不另建重复任务。批次关联任务由批次面板统一控制。读取目录的在途请求可能等到有界超时后结束，停止后迟到结果不会创建新任务。

## 作品工作台

添加网页作品后先展示目录标记开放数、目录受限数；来源未开放时显示待验证数，不因 restricted=false 声称免费。“仅保存目录标记开放章”一次选择全部开放标记位置，跳过目录明确受限项；自定义范围继续保留，可明确记录所选受限章。实际开放状态以获取结果为准，目录不是阅读权益证明。没有自动购买、广告解锁或自动寻找第三方正文。

概览和保存正文页新增“缺章原因与下一步”，从核心详情读取逐章依据：本地已有正文优先，其次来源能力、最近确认目录及每章最近任务。后建的小范围任务不抹除其他章节的错误。分类包括访问受限、获取失败、等待、暂停、取消、未尝试、来源未开放与待核对；保留原始错误而不从关键词推断登录或订阅。明细每页 50 章，支持类型与标题/序号筛选，并链接到原任务。只读报告不请求官网，不改变任务状态或原书库正文；旧记录无依据时明确待核对。

从书架点击“打开作品工作台”，一本书的保存、阅读和导出都在这里完成。新下载/导入任务创建后直接打开对应作品；起点确认目录后直接进入工作台的“保存正文”，保留选定账户。

- **概览**：显示书库实际保存数和下一步。只保存所选章节时，即使任务完成，整书仍显示缺章。
- **保存正文**：起点使用本书账户官网窗口；已支持网页来源可检查目录并补缺章。暂停/继续、任务记录和逐章原因在同页，批次任务仍从全局任务面板统一控制。失败或受限时优先继续原任务，另建任务放在高级选章选项中。
- **阅读**：默认只列出已保存章节，可检索或切换全部目录。同一工作台切换页签保留当前章节，更换作品或关闭软件后不承诺恢复阅读位置。
- **导出文件**：选择 TXT / EPUB、生成文件和打开目录；下方保留本书导出记录。格式记忆仅保存界面偏好，不保存账户凭据，不改变书库或默认导出目录；系统禁止界面存储时仍可本次导出。

键盘聚焦页签后，可用左右箭头切换，Home / End 到首尾页签。标签、归档、目录变更及历史版本保留在概览的高级操作中。

## 书库、阅读与导出

书架每页最多显示 48 本，底部可切换首页、上一页、下一页和末页。搜索书名、作者或标签会检索全部作品并回到第一页；可切换书架/已归档/全部。详情中修改逗号分隔的标签和归档状态；这些本地字段不随来源更新覆盖。归档不删除正文。

目录按每页 100 项显示，可检索并预览已保存章节。TXT 为 UTF-8，EPUB 为 EPUB 3。书库导出包含该书全部已存正文；任务导出只包含该任务选择的集合；缺章会标为部分内容。同名文件已存在时会明确提示并保留原文件；可从详情中的导出记录打开原导出，或使用 CLI 的 --output 选择其他目录。重复导出不会新增记录。

“检查更新并补齐”自动处理不变目录和末尾新增；若出现删章、重排或插章，打开“目录变更与历史版本”先预览，再明确确认。确认会保存旧快照，10 分钟后预览过期需重新读取。该书有待执行或暂停任务时，先完成或取消任务。

选择已保存章节后，可检查该章正文修订。实际变化才保留旧文并更新；网络失败、取消、标题或身份不一致均保留原文。历史快照可查看旧章并导出。界面显示最近 20 个快照，更多记录可用 CLI；不自动清理历史。

## 备份与恢复

“备份与诊断”中创建一致性备份，程序给出包含 manifest 和数据库的目录。备份包含书库、任务、标签、修订历史、导出记录与非敏感账户别名；不复制导出文件、浏览器会话或凭据。

填写该备份目录恢复时，先校验 SHA-256、完整性、版本与数量，再恢复到全新副本。成功后可打开独立窗口；不会替换当前书库。外部导出文件可能仍指向原位置，可从恢复副本重新导出。

迁移前自动备份和手动备份都应另行保存到可靠存储。旧程序不能直接打开较新的 schema；需要恢复兼容备份到独立目录。卸载器默认保留数据；选择“删除应用数据”前请先备份。

## 平台账户实验

提供起点四步保存引导和书旗临时官网窗口。起点点击“打开官网登录”，通过官方书架正常跳转登录页，不依赖首页登录弹层。软件只报告窗口打开，不自动判断已登录。多个本地账户可在页首切换。

填写不含登录参数的起点作品链接后，使用“打开作品目录”查看作品；“高级操作”中的书旗入口打开官网首页。请在官网本人完成登录，不要把密码、验证码或 Cookie 填入本软件或问题报告。

不同账户使用独立临时浏览器环境；关闭窗口结束会话，下次需重新登录。“关闭并清理会话”先清理本机浏览数据再关闭，移除记录保留书库。当前不提供自动登录检测、凭据持久化或其他设备退出。起点提供当前页保存和自动逐章保存实验；真实已购权益与 VIP 全书覆盖尚待用户本人配合验收。

### 起点：自动保存全书（实验性）

1. 在“添加小说”粘贴起点官网作品链接，点“下一步”，软件自动进入起点保存引导并带入链接。
2. 第 1 步点“打开官网登录”，首次自动建立本地账户记录。请在官网亲自完成登录，再回到软件。
3. 第 2 步点“打开作品目录”，在官网切到目录并展开全部章节。回软件点“读取作品目录”，核对书名、作者、章数和首末章，再点“确认这本书”。已有作品可用“继续已有作品”选择，免去重复粘贴和确认目录。
4. 确认后会进入本书工作台，保留所选账户。在“保存正文”中本人先关闭官网自动订阅，再勾选软件确认项，点击“自动保存全书”。默认保存缺章；先试用可展开“限定章节范围”，填 `1-3`。软件不点击购买按钮。
5. 保持官网窗口打开，请勿手动切页。可暂停、取消或继续原任务。关闭软件后进度保留，下次重新打开官网登录后继续。
6. 遇到订阅、登录、验证、保护、页面变化或超时，队列停止并显示原因，后续章节保留未保存状态。本人处理后再明确继续，不会自动购买或无限重试。
7. 在工作台切到“导出文件”：已保存至少一章后，选择 TXT（普通文本，推荐）或 EPUB（电子书阅读器），点“导出文件”，再点“打开文件所在文件夹”。缺章时生成部分内容，目录或所选完成不代表全书完整。

保存正文页面的“高级操作”保留手动逐章保存、添加多个账户、关闭/移除会话和书旗官网窗口。关闭官网会话会结束临时登录，但不删除书库和任务进度。

自动会话任务只从桌面账户入口启动或继续，CLI/普通 HTTP 入口不能运行。同一时间只执行一个官网自动任务，默认快速节奏最小翻页间隔 1 秒（实验），可选标准 3 秒或缓慢 6 秒，单章最多 30 秒。节奏在启动/继续时生效，运行中需要先暂停再改；旧客户端省略节奏仍使用 3 秒。真实 VIP 全书仍待本人配合验收，不能保证所有订阅作品都能保存。

公开网页默认请求起始间隔从 1 秒调整为 0.5 秒；可通过启动环境 `OPENNOVEL_HTTP_INTERVAL_MS` 在 250～60000 毫秒内调节，无效值回退 500。仍为串行完整正文处理，不并发操作账户窗口。服务器 429 / Retry-After 优先，不能以快速节奏覆盖退避；验证、付费提示及异常仍停止。快速模式可能更早触发平台限流，遇到时请改慢并处理官网提示。

1000 个未保存章节的起点节奏下限由约 50 分钟降至约 16.7 分钟，网页节奏下限约由 16.7 分钟降至 8.3 分钟；这只是忽略加载等耗时的推算，不是全书实测或完成时间承诺。已保存正文仍跳过。网络、页面渲染和平台限制可能占据主要耗时。

### 起点：保存当前可读章节（实验性）

1. 按上方引导打开官网登录与作品目录，再展开页面底部“高级操作”中的“保存当前可读章节”。
2. 在同一官网窗口切到目录，展开全部章节。回软件展开“保存当前可读章节”，点“读取完整目录”，核对书名、作者、章数后“确认保存完整目录”。未完全加载时会报错，不写入局部目录。
3. 在同一官网窗口手动打开你有阅读权限的一章完整正文。回软件点“预览当前章”，核对标题、正文首尾，再点“确认保存当前章”。不要在读取过程中切换页面。
4. 重复步骤 3 保存其他章节。可从“在书库查看”离线阅读，也可“导出已保存 TXT/EPUB”；未存章节会显示缺章提示，未收齐不标成完整。

仅识别 `www.qidian.com/book/数字/`（含 `/catalog/` 目录页）和 `www.qidian.com/chapter/书号/章号/`。其他阅读地址、未知结构、未购提示、试读截断、保护字形或尚未加载完整会拒绝保存，不需要提供 Cookie。预览 10 分钟过期，关闭账户窗口后需重新读取。同章重复保存不会产生重复任务；内容不同时拒绝覆盖。当前只接受目录末尾增章，目录重排应先保留原书库等待后续适配。

目录解析、字数检查和用户预览仍不能代替真实逐章验收。自动翻页使用上面的独立入口；手动保存仍可用于逐章核对。可读页面能否成功保存，要以实际作品和页面结构为准。

## 诊断和问题报告

先预览诊断 JSON，再决定保存分享。固定内容只有版本、系统、schema、数量、任务状态和完整性布尔值，不含书名、正文、路径、标签、账户与网络错误原文。问题报告建议包含版本、来源、公开作品链接、操作步骤和可复现现象，不附数据库或完整平台正文。

## CLI 补充入口

运行 `opennovel --help` 查看所有命令。使用源码时将前缀替换为 `cargo run -p opennovel-cli --`。以下 ID 均替换为本机实际返回值；目录选择全新的路径。

```powershell
opennovel --database .artifacts/library.db search 书名 --source jinjiang-web
opennovel batch book-links.txt --chapters "1,3,5"
opennovel batches
opennovel batch-resume BATCH_ID
opennovel organize BOOK_ID --tag 收藏 --tag 连载 --archived
opennovel backup D:/NovelBackups/new-backup
opennovel restore D:/NovelBackups/new-backup --output D:/NovelRestored/new-copy
opennovel diagnose
opennovel diagnose --output D:/NovelReports/new-diagnostic.json
opennovel update-preview BOOK_ID
opennovel update-accept BOOK_ID --previous-hash PREVIOUS_HASH --proposed-hash PROPOSED_HASH
opennovel refresh-chapter BOOK_ID CHAPTER_ID
opennovel history BOOK_ID
opennovel read-history SNAPSHOT_ID CHAPTER_ID
opennovel export-history SNAPSHOT_ID --format epub --output D:/NovelExports/new-folder
```

`update-accept` 要求与先前预览一致的前后摘要；本地或官网已变化时拒绝。`organize` 未加 `--archived` 表示回到书架；标签以本次指定集合替换。CLI 不控制另一进程中的任务或账户窗口。
