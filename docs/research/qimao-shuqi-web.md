# 七猫与书旗官网研究

日期：2026-10-21。实现版本：0.2.0 候选版。仅研究正常公开网页与官网部署资源，无账户、无 Cookie、未使用第三方正文接口。在线页面保留于忽略目录 `.artifacts/v02-research`，不分发正文；自动化样例独立原创。

## 七猫：第二个正文适配器

实测作品为 [离婚后她惊艳了世界](https://www.qimao.com/shuku/222767/)，远端 ID `222767`。详情页返回作品信息、简介、目录声明数量和最新章节链接。官方部署脚本 [6172a96.js](https://cdn-front.qimao.com/qimao/pc/js/6172a96.js) 的 `get_book_chapter_list` 调用 [目录接口](https://www.qimao.com/api/book/chapter-list?book_id=222767)。据此独立实现请求和解析，未复制参考下载器代码。

本次目录包含 4100 项，其中 `is_vip="0"` 为 14 项、`"1"` 为 4086 项。以字符串保留章节 ID，要求 index、chapter_sort 为连续的 1..N，作品页声明数量与接口长度相同，末章身份与详情页链接一致。任何未知权限、缺失字段、重复章节或身份错误均拒绝入库。目录在两个请求间变化时可能被拒绝，应重新读取，不能用不完整目录替代。

正文从官网 `/shuku/{book}-{chapter}/` 请求。第一章 ID 为 `16480917400001`，第 3/5 章为对应末尾 `0003`、`0005`。主章节容器具有标题、声明字数和正文段落；第一章声明 1758 字，正文为可读中文。本轮保存第 1/3/5 章，第 15 章按目录权限标记受限，下载引擎不请求受限正文。

研究受限页面时发现整页仍包含**其他作品的推荐正文**。收集全页 p 标签会误存推荐内容。本实现限定 `.chapter-detail-wrap > .chapter-detail-wrap-content` 内的主文章，检查路由作品/章节身份、标题、声明字数与实际长度，并拒绝未知私用字形和 XML 非法文本。80%—150% 的长度范围用于检测明显截断/污染，是保守启发式；不能替代更多作品抽验，也不能证明页面没有细微缺字。

网页 VIP 标记不按“App 广告免费”解释。App 免订阅、广告解锁与网页开放是不同条件；本轮不实现 App、登录或订阅正文。

### HTTP 响应兼容诊断

初次 Rust 实测在七猫返回 `client error (SendRequest)`，番茄、书旗正常。最小 reqwest 诊断定位为 `invalid HTTP header parsed`。TLS 原始响应显示安全头行带前导空格，属于旧式折行头；严格 HTTP/1 解析拒绝，而 Python urllib 能读取。同样现象在当前系统代理和直连诊断均出现，未变更系统代理。

修复是仅七猫客户端启用 reqwest `http1_allow_obsolete_multiline_headers_in_responses(true)`。未关闭 TLS、未全局忽略无效头。原创本地服务器回归复现相同格式，验证默认严格客户端失败、兼容客户端成功、未知 URL 主机仍被拒绝。修复后真实 Rust inspect、下载和原生恢复通过。兼容项随来源变化复审。

## 书旗：先接详情和完整目录

实测作品 [短月集](https://www.shuqi.com/book/9147568.html)，ID `9147568`。详情页 `.js-pageData` 是独立 JSON，提供作品身份、名称、作者；简介取展示字段。解析 HTML 解码后的 JSON，**不执行内嵌 JavaScript，不读取页面临时令牌**。

[完整目录](https://www.shuqi.com/chapter?bid=9147568) 返回 11 章。读取 `.chapterul` 的 reader 链接，校验官网 HTTPS 主机、路径、作品 bid、章节 cid、连续序号及声明总量，拒绝错书、重复和不完整集合。不能把详情页目录预览当成全目录。

正文样本 [reader](https://www.shuqi.com/reader?bid=9147568&cid=2384430) 两次返回 HTTP 429，第二次明确 Retry-After: 62。未继续密集请求，也未借用令牌、账户或其他渠道尝试绕过。本轮结论仅为：**当前获取条件未通过正文验收**，不是网站永远不可访问，也不能推断其他作品可下载。

Shuqi 只实现 inspect，不实现 SourceAdapter。来源 can_download=false；GUI 展示原因、禁用下载，CLI/core 建任务前拒绝。目录没有权限字段时 restricted=false 仅表示“未见明确受限标记”，不得标成可下载。

## 共用层与后续研究

复用任务事务、缓存、取消恢复、详情和导出；HTTP 层保持各自域名名单、预算与每客户端请求间隔。恢复依据数据库中的来源 ID，不能默认调用番茄。前端展示能力，核心执行同一限制。

后续顺序：书旗正常网页正文条件复验 → 七猫更多作品与目录变化 → 起点/晋江公开目录、免费试读 → 账户及已购内容评估。每项以实际样本、错误与完整性证据准入，不承诺未购买 VIP 获取。本轮详见 [实测记录](../verification/2026-10-21-multi-source.md)。
