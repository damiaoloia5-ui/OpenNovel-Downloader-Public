## 新增实现

### 宿主 HTTPS broker

`scripts/research/https_read_gate.py` 限定 `novel.snssdk.com`、固定路径 `/api/novel/book/reader/content/v1`、精确参数及白名单请求头。请求由候选生成的签名和临时握手字段仅在受限传输中使用，没有将候选算法或常量复制进核心。

- 只允许 GET，无 Cookie、账户认证、请求体、通用 URL、注册、权益、评论或媒体入口。
- 丢弃容器传来的 Host；DNS 所有候选地址须为公网地址，连接选定地址并以固定主机名进行 SNI 和 TLS 证书验证，不使用环境代理。
- 禁止重定向、自动重试、换身份和多接口回退。挑战、401/403、429、重定向及错误状态不读取响应体。
- 读取上限 2 MiB 加一个判溢出字节，分块读取阶段共享 12 秒预算，单次连接/请求等待使用 12 秒 timeout。DNS 系统调用和 HTTP 头解析不是独立硬实时总预算，不据此声称整个程序必在 12 秒内退出。
- 成功 HTTP 或 code=0 均不自动算完整正文。仅转交必要的内容编码与握手响应头；正文和临时字段不写普通日志。

### 网络隔离与临时邮箱

`relay_read_gate.py` 保持 `network=none`，与引擎共用无网网络空间。引擎没有独立外网接口。请求经能力前缀和精确参数校验后进入容器 tmpfs 邮箱；宿主通过 Docker exec 的标准管道读取，再次校验并代发单次固定 HTTPS 请求。响应经管道回填 tmpfs，不通过通用代理或 Docker socket 给引擎联网。

引擎、relay 容器均非 root、只读根目录、丢弃全部 capabilities、不映射宿主端口；候选运行时仅挂载产物卷为只读。容器日志驱动显式设为 `none`，避免验收正文被 Docker 自动记录。临时请求、密文和握手状态仅保留在内存、管道和容器 tmpfs，结束后删除本轮容器。普通研究模式只输出白名单元数据。

邮箱服务只接受一次匹配请求，重复请求拒绝，没有队列自动重试。该设计是单章验收工具，不是已经完成的可持久恢复下载服务，也不能直接用于高吞吐全书下载。

### 核心校验与保存

`crates/core/src/sources/fanqie_engine.rs` 是独立编写的明文信封解析器，不加载外部核心或增加网络权限。强制 schema_version、作品/章节身份、章节标题、整数字数和 need_pay 字段；拒绝未知/重复字段、超大响应、付费项、预览提示、缺字、脚本/图片/隐藏内容和未知字形。段落字数必须精确等于声明字数，然后复用现有 ImportDocument 校验。

`crates/core/examples/accept_engine_chapter.rs` 在解析完成后才创建全新输出目录。复用现有 Library 导入的事务及 TXT 导出，不修改 schema 或覆盖用户库。目录已存在时拒绝创建，不重写原有文件。

外部原始响应传给核心的验收信封仅包含固定字段；宿主先拆分出信封，确认参考对照通过，再通过 stdin 交给核心示例。元数据报告不包含信封正文。信封自身不是官方签名或可信证明，未来集成仍必须保持调用进程和通道的信任边界，不能允许陌生服务直接注入数据。
