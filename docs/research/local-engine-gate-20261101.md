## 具体边界

### 单章封装

`scripts/research/engine_probe_examples/opennovel_readonly_probe.rs` 为本项目原创评估代码。仅在隔离候选构建中链接其公开接口，不属于 OpenNovel 的 Cargo workspace，也没有把 GPL 引擎直接链接到主程序。

它通过标准输入接收最多 4096 字节的 JSON，只允许一个 `item_id` 字段，且只能是原创测试 ID `10000000002`。不接受 URL、请求头、账户、文件路径、通用操作或任意章节。每次运行生成独立临时目录，不读取原程序设备文件。

封装直接调用候选的单章临时握手内容函数，未初始化整套路由服务器或桌面桥接，不开放默认 full/批量/媒体/账户等分支。上游与设备注册器的 mock origin 均指向固定 `127.0.0.1:8123` 的 broker，携带每次验证新生成的能力前缀。调用有 5 秒总预算，失败只输出固定提示。结果需 code 为 0、测试章节身份一致、内容非空且有界，并检查设备池数量及池文件副作用。

候选仍在测试请求中执行自身签名/握手代码，但 broker 仅返回原创明文 fixture，没有实际服务器握手或真实响应；本轮不能证明官方签名、加密和权益流程成立。未来变为真实章节前仍需要独立的权限与完整性验收。

### broker

`local_engine_gate.py` 是**无转发能力的离线测试服务**，不创建上游 HTTP 客户端。只绑定网络空间内的回环端口，不暴露宿主端口。每次验证生成 256 位随机能力，仅传入验证容器；日志不记录能力、请求目标、请求头、签名、正文或任意服务器消息。

broker 只允许一个精确路径、固定测试 ID 和固定参数集合，重复/多余/缺失参数拒绝；仅 GET 且不能携带正文、Cookie 或认证头。其他已处理方法一律拒绝，未实现的方法由 HTTP 服务返回非成功状态。请求头有 Python HTTP 服务本身的解析限制，单连接有 3 秒超时；该工具不是面对不可信公网流量的服务，不承诺抗拒绝服务能力。

仅靠默认拒绝路径不是操作系统级出口防火墙。真正的执行隔离来自容器 `network=none`：引擎即使试图绕过 mock origin，也没有正常外网出口。broker 也没有外网接口，因而不能转发任何被接受或被拒绝的请求。容器逃逸、宿主/daemon 威胁和恶意依赖审计不在本轮覆盖范围内。

### 构建与进程隔离

`run_local_engine_gate.py` 只复用阶段一已存在的固定源码清单、预取依赖卷和本机镜像，不自动下载源码、安装引擎、pull 镜像或访问章节。

- 构建：`--network none`、非 root、只读根目录、丢弃全部 capabilities、禁止提权、限制 CPU/内存/PID；源码和原创封装只读挂载，cargo/target 为专用缓存卷。
- broker：同样无网、非 root、只读根目录，仅挂载研究脚本目录为只读。
- 候选执行：加入 broker 的无网网络空间，只挂载构建产物卷为只读；无源码目录、主书库、浏览器、用户目录或 Docker socket 挂载，无对外监听。
- 编排程序通过 Docker 创建每个容器后核对实际 inspect 配置再启动；完成后只停止、删除本轮精确容器 ID，不清理其他项目容器或缓存。

首次启动失败是只读源码缺少 `rust/examples` 挂载点。修复方法为在忽略目录内创建独立构建副本、预置空挂载点，再以只读方式挂载；原始源码未变。没有通过放开容器写权限或移除只读保护修复。

Rust 镜像固定为 `sha256:e18a79fc84dfcfc3ab5ba72290398a644c135c97eaa881447fddc354ee4701a3`，Python 镜像取本机已安装镜像的不可变 ID，并记录于证据。原始候选提交仍为 `07cfb2249d4fd57d19bf4420af0e97621ec92df9`，其许可证和分发限制保持阶段一记录；本轮不作任何打包或再分发决定。
