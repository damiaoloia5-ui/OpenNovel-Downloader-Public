# 纵横、17K、刺猬猫、咪咕与飞卢接入

调研日期：2026-10-31。独立实现，不读取或复制其他下载器源码。本轮使用官方公开页面、无账户、无浏览器自动化。页面原始样本和正文仅留在忽略目录，不提交仓库；CI 只使用原创样例。

## 已实施

后续同日实施：三家的隔离官网会话及页面识别已实现；刺猬猫/飞卢增加经确认的可见普通文字独立 TXT。咪咕改用可访问的 cmread.com 悦看官网，正文仍未验证。以下“尚未实施”表描述完整目录与正文适配的前一阶段缺口；最新范围、限制和未验收账号见 [后续验证](../verification/2026-10-31-official-reader.md)，不能把本次会话入口当作全书适配。

纵横使用 [官网详情](https://www.zongheng.com/detail/1479797)、[旧版官方完整目录](https://book.zongheng.com/showchapter/1479797.html) 与 read.zongheng.com 免费正文。新版详情的 catalogue 标签在服务器 HTML 中为空，不能据其两条首末链接伪造完整目录；旧版官网提供分卷总数和逐章 VIP 标记，适合先接入。逐卷数量、全局数量、链接所属作品与重复 ID 均核验，顺序独立于章节 ID。正文要求 data-bookid/chapterid、data-vip=0、data-ec=0、空 decoder、精确标题与声明字数；不尝试解除保护。旧页面若下线或结构变化，失败保留本地内容。

17K 使用 [官网详情](https://www.17k.com/book/3583700.html)、[完整目录](https://www.17k.com/list/3583700.html) 和公开 chapter 页面。分卷有“已更新 N 章”与 VIP 样式标记；正文独立检查页面的 $__BOOK 身份与 vip=0。仅解析数值字段，不执行脚本。正文容器混有版权声明、作者附言、广告和二维码，因此只保留直接段落，排除已观察到的固定非正文块；其他未知元素与样式拒绝，避免把试读或其他内容当成正文。声明字数比例仅是保守启发式，不能证明每个作品逐字正确。

两家使用独立 HTTP 客户端和严格域名白名单，保留已有响应上限、超时、取消、节奏和 429/Retry-After；GUI 和 CLI 共用核心，复用事务、持久任务、范围选择、缓存、部分导出及后台自动 TXT。没有数据库迁移或来源身份合并。

## 下一阶段的完成标准

每次新增来源分别完成：官方 URL/身份契约、完整目录及顺序证明、明确限制状态、免费正文真实性与反截断、受控异常/中断测试、真实小样本、GUI/CLI 闭环及来源状态文档。先开放通过的能力；无法证明目录完整性则拒绝建任务。其他平台按相同门禁接入，不引入能任意请求地址或执行第三方代码的通用爬虫插件。
