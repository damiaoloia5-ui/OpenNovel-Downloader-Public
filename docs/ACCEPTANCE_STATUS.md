## 如何补齐剩余门禁

1. 用户方便时在独立的官方窗口本人登录书旗，提供具有权益的干净作品链接，观察登录/退出/过期及免费/已购/未购差异；有证据后实现对应来源适配，再进行真实正文完整性和导出验收。起点需先解决正常官网可访问条件。
2. 在另一台干净 Windows x64 或用户准备好的虚拟机中，分别验证 WebView2 已安装和缺失两种环境。当前机器固件虚拟化为关闭，未发现 Sandbox/Hyper-V 入口，不能自动修改 BIOS 或用同机测试替代。
3. 依次验证安装、启动、JSON 文件选择、公开来源小范围下载、离线阅读、EPUB、备份恢复、默认卸载保留和明确删除数据分支；只用原创/受控数据验证删除分支。
4. 将环境、安装器 SHA-256、步骤和实际结果写入记录。通过剩余门禁后再确定稳定版本；tag 和 push 均需用户明确授权，不能自动执行。
