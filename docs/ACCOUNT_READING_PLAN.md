# 账号权益内连续保存

产品规则：软件不按 VIP 等级设置每日章数、字数或下载次数配额。读取范围由本人账号在官网实际拥有的章节权益决定。VIP 标志、包月、单章订阅、限免各自的覆盖范围不能相互代替；网站登录成功也不代表所有作品已经可读。

## 当前实施状态

- 起点：已有本人独立官网会话、完整目录确认、连续保存、缓存跳过、停止后继续及自动 TXT；真实已购全书仍未验收。未购提示、验证码和失效会话停止并保留进度。
- 纵横、17K、晋江、七猫、书旗、刺猬猫、飞卢：v0.3.17 接入独立来源 `*-session`，使用本人的隔离官网窗口、公共目录确认、稳定正文校验、连续保存与停止恢复。普通 HTTP 不接收账户凭据。真实已购全书未验收，未知布局、缺少字数、图片正文等停止并保留进度。
- 刺猬猫两本公开首章在真实 Edge 渲染中识别成功；飞卢样本正文是图片，不能因已有队列入口就声称已能下载。咪咕目前仍仅作品页识别，七猫 App 通道未实现。
- 用户没有书旗已购作品，本轮不要求购买，已购、包月、过期状态的真实账号验收继续保留，不能用原创回归替代。

v0.3.13 取消已有正文渠道的“最多为声明字数 150%”限制、起点及当前页采集的 20 万字上限；番茄完整封装不再要求正文与平台声明字数精确相等。没有新增按会员收费或限额逻辑。响应大小、段落数量、单次目录容量等资源保护仍保留，它们不是阅读权益或每日额度；超大作品后续通过分批目录和流式处理扩展，不能宣称无限内存或无限请求频率。

## 其他平台接入方式

已完成共用会话任务与目录连接，后续按下列门禁逐平台完成真实账户验证。只有 App 可读的内容不能用网页登录替代；咪咕需先取得可验证的官方正文路由。参见 [v0.3.17 验证记录](verification/2026-11-03-remaining-platforms.md)。

每个新平台需完成以下真实验收后才能标记支持：

1. 作品及目录身份、完整页数与顺序核对，章节 ID 与顺序分离。
2. 用户本人在官方临时会话登录，软件不保存密码或将凭据写入书库；不自动购买，不启用自动订阅。
3. 已购可读、未购、已登录但不在会员范围、权益过期分别检查；以实际正文和限制状态决定保存，不能用“VIP=true”直接放行。
4. 每章页面稳定后校验来源、书籍、章节、正文容器和权限提示；图片/未知布局不冒充普通完整正文。
5. 主动停止、验证码、登录过期、进程重启后，保存进度仍可恢复；每章正文和完成状态同事务提交。
6. TXT/EPUB 与已保存内容一致，缺章明确标记；实际已购全书测试与原创受控回归分别记录。

这些是后续平台接入及验收要求，不能把本文件或登录按钮当作已经支持全部平台 VIP 的证明。
