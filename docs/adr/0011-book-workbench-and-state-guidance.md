# 0011：作品工作台和状态引导

日期：2026-10-26；状态：已实施，完整原生交互及真实账户权益按验证记录保留门禁。

## 问题

读者需要在账户、全局任务、书库详情和导出入口之间切换。目录确认与任务创建后缺少围绕同一本书的连续操作，所选任务完成与整书收齐容易混淆。

## 决策

- 提取 BookWorkspace，提供概览、保存正文、阅读、导出四个页签。全局添加、任务、账户及维护入口保留；已有标签/归档、历史与任务选章导出仍可到达。
- 书架、任务和新下载/导入任务统一使用核心返回的 book_id 打开工作台；不从书名或链接猜本地身份。起点确认目录后带上所选账户进入保存页。
- 前端流程模型集中区分账户会话、公开网页、本地导入与未开放来源。普通网页来源仍由核心 can_download 控制；qidian-session 仅进入既有账户流程，不开放普通 HTTP 能力。
- 整书完成由书库实际 saved_chapters/total_chapters 判定。运行、暂停、失败/受限与缺章给出不同下一步；任务范围计数单独展示。查看工作台或切换页签不会自动启动、恢复或购买。
- 前端只调用既有 IPC，不抓正文、不写 SQLite。GUI/CLI 共用核心、事务、暂停恢复和导出保护均保留，schema 不变。
- 工作台依赖全局持久快照更新计数，细节变化时重新读取；保留当前阅读章节、检索和选定账户。切出保存页停止该组件的界面轮询，后台任务继续由核心控制。
- 使用加载代次、组件销毁标记和导航代次阻止迟到结果更新错误作品或把用户拉回旧页面。历史明细后台刷新保留筛选与分页。
- 起点失败/受限优先继续原任务；另建范围任务保留在高级选项。更换账户或重新进入保存页后仍需本人确认官网关闭自动订阅。
- 只在界面存储记住 TXT/EPUB 格式，不保存路径、账户凭据或阅读权益。界面存储被禁用时退回默认格式并允许本次导出；不改变核心导出目录、不覆盖旧文件。

## 验证边界

新增原创流程模型回归及受控实际 Vue 页面操作，覆盖范围完成、多账户、任务恢复、未支持来源、导出格式、页签保留、修订刷新和迟到导航。原生最终构建启动及导航已观察；用户停止 Computer Use 并要求后续禁用，原生导入/阅读/导出未完成验收。当前源码 CLI 原创导入导出另行验证，不将其替代原生或 VIP 权益证据。
