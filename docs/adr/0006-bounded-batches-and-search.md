# ADR 0006：有界批次与来源搜索

2026-10-21，已实施于开发分支。

批次是多个普通持久任务的顺序容器，不建立第二套章节下载器。为避免进程在“建任务成功、批次尚未记住任务 ID”之间中断而创建孤儿任务，关联写入与普通任务创建共用事务。批次世代号限制迟到的目录结果，暂停/取消后目录不能创建任务。恢复使用既有关联，普通任务入口不能抢占批次拥有的活动任务。

每批 10 本、待处理 5 批、同时执行一批，以显式选章防止一次输入造成无界请求。按来源和作品身份去重，不按标题合并；网络错误暂停整批，保留原因，用户确认等待条件后继续。已终结批次保留逐项结果和普通任务详情。

来源搜索属于可选能力。只有晋江正常官网表单与真实首屏结果经过验证，才能声明 can_search=true。最多 20 项，结果保留来源/远端 ID，选择后仍经完整目录与正文校验。不因为 HTTP 200 或页面可打开而声明其他来源搜索可用。

schema 6 仅新增批次表，迁移前备份；核心契约测试与原生重启继续证据见 [验证记录](../verification/2026-10-21-batch-search.md)。
