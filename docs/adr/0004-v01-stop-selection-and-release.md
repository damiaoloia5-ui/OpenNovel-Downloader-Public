# ADR 0004：首版停止边界、选章导出与发布范围

日期：2026-10-20。状态：已实施；安装的独立干净系统验收仍待补。

## 问题

已有网络闭环缺少独立暂停、离散选择和离线预览。只设置内存取消标记不能阻止晚启动的 worker 或迟到响应提交；按书籍导出会把其他任务缓存混入新选择范围。发布还需要安装、迁移和依赖通知。

## 决策

- 在同一个数据库互斥区更新停止状态和活动 token；启动与正文提交都检查状态。暂停/取消保留已提交章节，停止后的迟到结果不提交。同一作品的活动执行注册直到 worker 真正结束才移除。
- 来源使用异步 HTTP 客户端，由核心同步契约桥接到进程共享的两线程运行时。取消分支每 25 ms 检查 token，丢弃请求 future；限流等待也检查取消。保留域名白名单、响应大小、重定向与超时预算。
- 选择保存为任务内不可变章节 ID 集合；顺序来自目录独立位置。任务导出过滤到该集合；书库导出保留显式“全部本地保存内容”语义。已保存章节可复用，不改变旧任务的选择。
- schema 4 新增导出记录；先写临时文件、同步并无覆盖落盘，再记录结果。迁移前用 SQLite 备份 API 保存旧书库；导出失败不回滚正文。文件系统与数据库不是分布式事务，文件落盘后记录失败可能留下未登记文件，错误需如实返回。
- 离线阅读只读取本地正文，不触发来源抓取。目录每页 100 项；前端渲染纯文本，系统文件夹入口只接受库内导出记录 ID。
- v0.1 经用户确认仅覆盖官网实际开放正文，App 与账户留待后续。Apache-2.0 为项目许可证；依赖保持原许可证，安装包包含锁定版本的通知。安装的本机证据不替代独立干净 Windows 门禁。

## 代价与后续

继续使用一个进程内受保护的 SQLite 连接，以正确性优先；万章详情仍会一次返回目录元数据，导出也会物化一份正文快照。若大型书库测试触及预算，再引入只读连接和流式导出，不能无证据宣称内存与书长无关。第二来源用于验证适配器通用性，不提前设计远程代码插件市场。
