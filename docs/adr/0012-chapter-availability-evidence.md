# 0012：目录可获取范围与逐章缺失依据

日期：2026-10-28。状态：已实施，原生交互与真实商业来源门禁另记。

## 决策

目录的 restricted 只能提供限制标记，can_download 只说明当前适配器的能力。界面可以据此呈现范围及生成已有选章接口的序号集合；不能据此判断每章完整正文、登录或订阅权益。未开放来源全部显示待验证。默认动作仅选择标记开放章，自定义选章入口保留，依然由核心校验与实际获取。

逐章缺失依据放在 core 的 book_details，只读取现有数据库，沿用既有 IPC 与 CLI book 命令。ReadingChapter 增加可选 availability（state/reason/job_id），旧序列化记录和历史快照允许为空；不增加数据库列或 migration。GUI 负责分类、筛选、分页与导航，不读取数据库或抓正文。

本地已有正文优先于远端限制与旧失败。没有正文时按未开放来源、最近确认目录、每章最近任务提供说明；任务错误原文保留，不以文本关键词推断登录/VIP。用 jobs.rowid 确定每章最近任务，避免秒级时间戳并列；未被新任务选中的章节继续保留旧任务依据。未尝试不等于不可读，queued 还需结合原任务的暂停、取消或停止状态。

概览/保存正文页呈现整个当前目录的缺章摘要，明细每页 50 项，可进入对应任务详情。报告不刷新官网，不自动恢复任务或跨来源拼书。账户目录只能证明作品与章序；限免检测、广告交互、其他官方版本查找均不是本次实现。

## 验证

原创受控核心测试覆盖范围外缺失、目录限制、失败停止、后建窄任务、同章重试恢复、跨书隔离、暂停/取消、本地导入、重启持久化、账户目录无权益证明、已存优先。前端模型测试及真实 Vue 组件的编译/服务端渲染检查说明与分页。不调用浏览器或窗口控制；原生构建不作为原生交互证明。
