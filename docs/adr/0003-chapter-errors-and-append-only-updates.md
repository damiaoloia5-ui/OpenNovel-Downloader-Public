# ADR 0003：逐章错误与保守目录更新

日期：2026-10-20。状态：接受。

此前任务只保留最后一条错误，长篇缺章难以解释；目录任意变化都会拒绝新下载，连载增章无法继续。这一阶段为免费平台第一版补齐管理能力，不扩大网页访问权限，也不接入付费平台。

schema 3 为任务项添加最近一次 `error` 和 `error_kind`，分为网络、访问限制、来源结构变化、正文校验、读写及其他错误。来源返回错误身份或无效正文同样落到具体章节，正文不入库。暂不建立完整尝试历史。旧 schema 1/2 的缺失错误不伪造，界面提示通过继续或检查更新确认。

任务详情统一由 Rust 核心返回，CLI 和桌面共享。失败章节可指定重试，待下载项不参与本次调度；状态声明、选项校验和错误项重置同事务执行。空选项、重复 ID、其他任务项、已完成项和访问受限项拒绝重试。受限项需要重读官网目录、创建新的补齐任务确认访问状态，不能靠重复请求改变权限。

指定范围仅约束当前运行，未单独建立重试子任务。取消或强退后继续原任务，会处理原任务所有待处理项；该语义在 CLI/界面说明。重试成功清除该章节最近一次错误，其余失败项及待下载项保留。

目录更新只接受旧章节 ID 序列是新目录的完整前缀。尾部新增允许；删章、插章、替换 ID 或重排拒绝。标题、作者与访问标记可随新目录更新。目录快照、作品总章数和新任务在同一事务中保存；有 queued/running/paused 任务时拒绝新更新。旧任务保持历史选章范围，作品覆盖率按最新目录统计。

新任务引用全目录，已保存章节复用，新章与其他缺失项按正常校验保存。已有正文不因元数据变化而覆盖；全文修订和中间目录重排另行设计。完整网络导出以 `complete-总章数` 区分快照，增章后可导出新文件；相同快照仍不覆盖。

旧书库在升级前以 SQLite 备份 API 生成 `library-v{旧版本}-backup-{UUID}.db`，失败则停止升级。普通 CI 的增章、受限转开放与定向失败使用原创受控来源，不请求真实账户或平台。原生验证使用真实来源与独立测试应用标识分别记录证据。
