# 0013：默认交付 TXT 的桌面后台

日期：2026-10-28。状态：已实施，原生交互另行验收。

用户希望识别后直接得到 TXT。普通已支持网页的主动作读取目录后直接创建标记开放章任务；原有预览、高级选章保留。起点仍走本人登录/确认，不能自动承诺或取得阅读权益。

自动生成逻辑属于 core，使用当前正文一致性快照与原 TXT writer。对输出字节流计算 SHA-256，文件名含安全标题、作品 UUID 与哈希摘要；同章数正文变动仍是新版本。文件用临时写入、同步与不覆盖发布；已有目标校验完整哈希后复用，用户编辑过的目标拒绝覆盖。记录按书/路径去重，修复丢失文件或“文件已发布但记录未提交”的中断，不增加 schema 或改变手动导出冲突语义。

桌面用独立单线程服务每秒读取轻量书库/任务快照，按作品身份与任务状态签名去重；只有空闲且有正文的作品才调用核心生成。含启动时已有内容、批次每本结束、网页/本地/账户停止后的已存正文。窗口最小化/切页不影响后台。相同数量修订/重排由成功命令显式通知强制重新核对。后台不导航/请求正文，不恢复任务，不购买。

状态在内存，实际正文、任务及导出记录持久化。一次失败不会每秒无限重试，用户可明确重试，或修复后重启；新状态也会重新核对。前端只获取状态、发重试、调用原有打开导出目录命令；不会因切换作品产生自动导出竞态。程序重启会基于实际字节恢复状态，不需要前端持有完成通知。

自动导出作为 GUI 默认体验，CLI 既有输出/API 保持兼容，GUI 调用与 CLI 原有导出继续复用同一 core。没有增加第三方服务或依赖，没有使用 Computer Use。原生构建、受控后台测试与真实权益验收分别记录。
