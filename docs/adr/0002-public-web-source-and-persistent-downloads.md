# ADR 0002：首个真实来源与持久下载边界

日期：2026-10-20。状态：接受实验实现，尚未作为稳定来源发布。

## 问题

本地 JSON 能验证保存、恢复和导出，但不能满足“免费小说平台第一版”的产品目标。真实来源还需处理目录顺序、网页受限、字体编码、请求预算和中断后的重复请求。付费平台是后续版本，不扩大本轮范围。

## 决策

先独立实现番茄官网公开网页适配。适配器只返回归一化目录与完整章节；Rust 引擎负责选章、持久化、恢复和导出，CLI 和 GUI 共用同一条保存路径。前端不解析网页或接触 SQLite。

不冻结动态插件 ABI。`SourceAdapter` 目前只抽象逐章获取，目录为共享数据模型；第二来源会检验并改进边界。来源内部管理 HTTP 主机白名单、响应上限、节流、超时及字体校验。

在 schema 2 新增独立的目录快照表，并保留每个远端任务项的章节元数据。网络 I/O 在数据库锁外执行；正文及任务项完成状态同事务提交。schema 1 升级前先创建 SQLite 备份，迁移失败不会静默降级。

任务状态增加 `partial` 与 `blocked`，原有 `failed` 表示执行失败。受限项不能算完成，临时错误停止当前运行，恢复时重试失败项并继续剩余项。新范围可复用书库已有章节。目录顺序或身份改变时暂时拒绝新任务，以后单独实现增量目录协调。

任务总数是所选范围，作品总数是完整目录，二者分别展示。部分导出文件名加入实际保存数与总数，保留先前文件；TXT/EPUB 包含真实来源信息。

## 取舍与后续

公开网页有维护成本较低、无需账户的优势，但实测长篇存在大量网页受限章节，因此只能标为实验性。字数比例及字段检查可发现明显截断，不能替代更广泛的人工正文对照。该来源不能用来宣称全站可下载。

当前 HTTP 使用阻塞客户端配合后台线程，取消最坏等待本次 20 秒超时。未来若体验需要立即中止，将迁移到可取消异步传输，保留现有事务和任务语义。尚未实现每章错误历史、动态目录更新或跨 CLI 进程的来源预算。

第一版仍以免费平台可用闭环、恢复、导出和安装验收为门槛；起点、晋江按目录/免费试读、账户与已购正文等能力逐层研究，没有未购 VIP 正文获取的已实现承诺。
