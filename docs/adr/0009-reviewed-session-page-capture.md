# ADR 0009：经预览确认的官网当前章保存

日期：2026-10-25。增加 `qidian-session` 独立来源，复用 schema 8；不等同于真实已购权限已验收或全书自动下载。

## 数据路径

本地主窗口发起一次读取 → Rust 选择该账户的独立官网 WebView → 确认 `https://www.qidian.com/book/数字/`（含 `/catalog/`）或 `/chapter/数字/数字/` → 固定脚本读取正常渲染 DOM → 原生回调返回 → 核心校验 → 内存预览 → 用户确认 → 核心事务保存 → 复用离线阅读及 TXT/EPUB。

使用已锁定 Tauri 2.12.3 的 `eval_with_callback`，没有远程事件回传入口，没有新增远程 IPC/capability、网络接口、登录信息导入或凭据存储。前端只展示预览和发起本地命令；解析与存储规则在核心，DOM 读取脚本随原生层固定分发。脚本不发网络请求、不访问 Cookie/storage、输入值、隐藏状态或页面应用数据，也不解码受保护正文。

## 信任和失败边界

- 读取前后检查实际窗口 URL、会话代次与导航计数。登录页、其他平台、不支持的旧式阅读 URL 不执行正文读取。URL 查询与片段只在原生内存中去除，返回结果不包含登录参数。
- 把 DOM 和回调数据视为不可信输入；严格字段、数值 ID、来源/作品/章节身份和 XML 字符校验；单次结果上限 2 MiB、目录上限一万章、单章二十万字符。读取超时 8 秒，同一账户不能重叠读取。
- 目录必须具有可见的官网总章数，且与去重后的同作品可见章节链接数一致。未展开、分页或虚拟列表不足时拒绝，不把局部目录当全书；目录不代表阅读权限。
- 正文只接受明确的阅读容器、匹配章节标题和可见声明字数。无可见正文、订阅/试读提示、canvas、未知结构或保护字形时失败。正文少于标注字数的 80% 时拒绝。该长度阈值是启发式检查，不能证明逐字完整；用户仍须核对预览首尾。
- 预览只在进程内存保留，有效期 10 分钟、全局最多 8 项；过期项在后续读取或关闭时清理；令牌绑定账户与会话代次，单次确认后消费，关闭会话失效。用户放弃前端预览后其令牌无法再由该界面提交，内存项在后续读取/关闭时清理。

## 持久化和顺序

作品身份为 `(qidian-session, remote_book_id)`，章节 ID 为原站字符串，顺序来自完整目录而非 ID 排序或保存时间。目录确认单独保存，正文与 completed 任务状态同一事务。无正文时导出返回明确提示；缺章导出保留缺失标记。

先保存后章再保存前章也按目录导出。重复相同章节不建新任务；不同正文或标题不会覆盖已存内容，保留原书库供核对。目录只接受原顺序的末尾增章，发生变化时保留历史快照；删章/重排暂拒绝。无需数据库 migration，不改变既有来源任务执行器。

## 能力声明

`qidian-session` 的批量 `can_download=false`，账户仍为 `open_unverified`，没有“已登录/全订阅”自动检测。仅平台账户页提供当前页面实验；CLI 可离线读取/导出已有书库，不提供账号登录或无头抓取。验证码、付款、自动翻页、自动订阅、权限绕过和保护机制解密均不在本次实现中。

验收分为核心原创契约、真实浏览器 DOM 契约、原生窗口/回调/交互、真实用户已购与未购页面四层。前面层级通过不能替代后面的门禁。

后续扩展：自动逐章任务由 [0010](0010-account-bound-automatic-saving.md) 另行定义。本 ADR 的手动预览流程继续保留；其中“不自动翻页”为该轮范围，不代表后续队列不存在。
