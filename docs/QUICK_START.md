# 第一次使用 OpenNovel

简明向导候选版，2026-10-30。先退出旧程序，再运行本轮目录中的 **启动简明版.cmd**。旧桌面快捷方式尚未更新。

## 免费网页小说

1. 在浏览器打开小说的作品介绍页，复制顶部地址。
2. 在“添加小说”粘贴地址，点 **开始保存为 TXT**。
3. 等保存结束，点 **打开 TXT 所在文件夹**。文件就是普通文本，无需另选格式或手动导出。

支持的平台由软件识别。默认尝试全部目录标记开放章，已有正文跳过；缺章时 TXT 明确标为部分内容。书旗目前只有目录，不能保存正文。

## 起点小说

1. 在“添加小说”粘贴起点作品链接，点 **开始保存为 TXT**。
2. 点 **打开起点，去登录**，在官网自行登录，再回软件点 **我已登录，下一步**。
3. 软件自动打开并尝试读取作品目录。核对书名、章数、首末章；本人在官网关闭自动订阅，勾选确认项，再点 **是这本，开始保存为 TXT**。
4. 保持官网窗口打开，不手动翻页。保存结束或暂停后，点上方的 **打开 TXT 所在文件夹**。

如果目录没读到：先在官网处理登录/验证码，或点“展开全部”显示完整目录，再回软件点 **我已处理，重新读取**。自动尝试最多 6 次，不会无限等待或自动处理验证。

窗口打开不代表已登录，目录章数不代表有阅读权益。真实已购全书和原生向导仍待本人验收，不保证所有订阅作品都能保存。

## 下次怎么继续？

打开“我的书库”，点 **查看进度与正文**。需要时按提示重新登录，勾选确认项，再点 **继续保存**。已经保存的章节不会重下；重复粘贴同一本书也会回到原进度。

书架上已有 TXT 的小说，可以直接点 **打开 TXT 文件夹**，不用先打开书籍页面。

## 卡住了怎么办？

| 看到的情况 | 怎么做 |
| --- | --- |
| 保存按钮是灰色 | 按旁边提示登录或勾选确认项 |
| 提示登录或验证码 | 在官网窗口完成，再回软件继续 |
| 网络或页面超时 | 检查官网能否正常阅读，稍后继续 |
| 有些章节没保存 | 展开“为什么有些章节没保存？”查看原因；已有正文可先取 TXT |
| 想休息或退出软件 | 先点“暂停保存”，进度会保留 |
| TXT 生成失败 | 修复显示的问题后点“重试生成 TXT”，书库正文仍保留 |
| 想调速度或只保存几章 | 保存页展开“更多设置”；默认 0.5 秒，遇到限流可改慢 |
| 想要 EPUB | 进入书籍的“其他格式与文件记录” |
| 想管理账号、查看来源或备份 | 左侧展开“更多功能” |

已有本地 JSON 可从“添加小说”底部的“其他方式”导入。只接受 OpenNovel 格式的 JSON，暂不直接导入 TXT/EPUB。

完整功能见 [使用指南](USER_GUIDE.md)，平台边界见 [来源状态](sources.md)。
