# 第一次使用 OpenNovel

可获取范围与缺章说明版，2026-10-28。软件右上角“不会操作？查看指引”和左侧“使用指引”随时可打开相同的分场景说明。

## 最先弄清两件事

**保存正文**：把章节放进软件的“我的书库”，可以离线阅读。

**导出文件**：把书库中的正文生成单独的 TXT 或 EPUB，便于用其他软件打开。只有目录，没有正文时不能导出。

## 从免费网页开始

1. 打开“添加小说”，粘贴番茄、七猫或晋江的官网作品链接，点“下一步”。
2. 核对书名与“当前获取范围”，点“仅保存目录标记开放章”。这是全部标记开放章，与高级范围设置无关；目录标记不保证实际可读。想先试用，可展开“选章设置与目录预览”，把结束序号改为 `3`，再点“保存自定义范围”。
3. 任务创建后直接进入本书工作台的“保存正文”页，暂停后可继续；受限内容明确标记。
4. 工作台固定提供“概览、保存正文、阅读、导出文件”四个页签；以后可从书架点“打开作品工作台”返回。
5. 切到“导出文件”，选择 TXT 或 EPUB，点“导出文件”，再点“打开文件所在文件夹”。会记住上次选择的格式。

书旗当前仅支持目录，不能保存正文。

若有缺章，在工作台“概览”或“保存正文”查看“缺章原因与下一步”。可以按类型、序号或标题检索，点“查看相关任务”核对原始错误与可重试项。报告只读取本地记录，不会自动请求官网；想重新核对网页目录，可从保存页检查目录并补缺章。受限并不单独证明需要付费，也可能是锁定、登录或渠道限制。

## 保存起点作品

1. 在“添加小说”粘贴 `https://www.qidian.com/book/作品ID/`，点“下一步”。链接会自动带入起点引导。
2. **第 1 步：打开官网登录。** 首次自动建立本地记录，不必先填写账户别名。请在官网亲自登录，软件不接收密码或验证码。
3. **第 2 步：确认作品目录。** 点“打开作品目录”，在官网切到目录并展开全部章节。回软件点“读取作品目录”，核对书名、章数和首末章，再点“确认这本书”。
4. **进入工作台保存正文。** 确认目录后自动进入本书工作台，保留所选账户。在“保存正文”页本人先关闭官网自动订阅，再勾选软件确认项，点击“自动保存全书”。若想先测试，展开“限定章节范围”，填 `1-3`。
5. 自动期间保持官网窗口打开，不要手动切页。需要休息时点“暂停自动保存”，回来点“继续此任务”。
6. **在同一工作台阅读或导出。** 至少保存一章后，切到“阅读”查看正文，或切到“导出文件”生成文件并打开文件夹。

下次可在“我的书库”直接打开本书工作台，不必重新粘贴链接或读取已确认目录。“平台账户”中也保留已有作品入口。关闭软件后需重新登录，但保存进度会保留。

官网窗口打开只表示窗口存在，不代表已经登录或有阅读权限。遇到订阅、验证、保护或不兼容页面会停止；本人处理后继续。真实 VIP 全书仍待验收，不能保证全部订阅作品都能保存。

## 已有本地文件

“添加小说”底部展开“其他方式”，点“选择本地 JSON 文件”。目前只支持符合 OpenNovel 格式、16 MiB 以内的 JSON，不直接导入 TXT 或 EPUB。普通下载不需要准备 JSON。

## 常见卡点

| 看到的情况 | 下一步 |
| --- | --- |
| 目录都是“未保存” | 还没有正文，先在本书工作台的“保存正文”中保存章节 |
| 起点开始按钮不可点 | 先打开账户官网窗口、确认目录，并本人确认关闭自动订阅 |
| 有目录但看不到保存入口 | 检查填写的链接是否和已确认作品一致，或从“继续已有作品”选择 |
| 目录不是想保存的书 | 停止确认，点“打开作品目录”后重新读取，避免保存错误作品 |
| 任务部分完成或停止 | 查看停止原因，已保存内容保留；处理原因后继续原任务 |
| 找不到导出的文件 | 导出完成后点“打开文件所在文件夹”；书库详情也有导出记录 |
| 提示同名文件已存在 | 旧文件保留，可打开已有导出；同章数不保证正文版本相同，先核对路径和内容 |
| 要添加第二个账户、手动逐章保存或打开书旗 | 在“平台账户”展开底部“高级操作” |

完整功能说明见 [使用指南](USER_GUIDE.md)，来源边界见 [来源状态](sources.md)。
