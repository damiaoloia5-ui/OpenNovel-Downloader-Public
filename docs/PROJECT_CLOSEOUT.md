## 外部验收操作单

在另一台 Windows 上由测试者本人执行：

1. 保存安装器 SHA-256、系统版本和 WebView2 初始状态；分别覆盖已安装和缺失分支。
2. 安装后实际打开窗口，导入随附原创 JSON，验证完整两章、阅读和自动 TXT，再删除该测试 TXT 验证恢复。
3. 用原创书库暂停、退出、重启继续，备份到新目录并恢复，核对章节及导出；不要用唯一的真实书库测试删除策略。
4. 卸载默认保留，再安装核对；明确删除应用数据仅用可丢弃原创测试库。
5. 基础包与一体化包分开验证；后者在不安装 Docker、Python、Rust、Node 的系统上检查首次启用、原生隔离失败提示、取消与恢复；另外验证 WebView2 缺失时离线安装分支。
6. 账号验收另行本人登录，逐章记录权限结果。不要在报告或聊天中上传密码、Cookie、Token、验证码或完整小说。

没有真实结果的项目留空或写未执行，不能预填通过。报告应附包摘要和实际步骤，不包含账户凭据。
